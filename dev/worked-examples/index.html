Worked Examples

Six canonical electrical worked examples per EARS REQ-162. Each section follows the same skeleton:

  1. Setup — variables, parameters, physical model.
  2. Propagation — symbolic sensitivity analysis.
  3. Uncertainty budget — tabular breakdown per JCGM 100:2008 §5.1.6 / EA-4/02.
  4. Numeric result — Symbolics.substitute with concrete values.

All six examples come with dedicated test items in test/examples/ (M1–M9 exit gates) or docs/src/ode-integration.md (M9) that assert the exact numeric outputs. Run the full test suite to exercise them end-to-end.

1. Ohm's law (GUM §5.1 canonical)

Setup. Voltage V ± σV and current I ± σI (independent, uncorrelated measurements). Measurand: resistance R = V / I.

using SymbolicUncertainties
using SymbolicUncertainties: ±
using Symbolics

@variables V I σV σI

v = V ± σV
i = I ± σI

r = v / i
# r.val = V / I
# r.err = (V/I) * sqrt((σV/V)² + (σI/I)²)

Propagation. The two operands share no common symbolic source, so the binary-operator path correctly applies JCGM 100:2008 §5.1.2 eq (10) for uncorrelated inputs.

Uncertainty budget.

budget = uncertainty_budget(r, [V, I], [σV, σI])
# Row per input: variable, sigma, sensitivity,
#   contribution, relative (fraction of variance)

Numeric result. Substitute V = 5.0, I = 0.5, σV = 0.01, σI = 0.001:

dict = Dict(V => 5.0, I => 0.5, σV => 0.01, σI => 0.001)
r_num = Symbolics.substitute(r, dict)
# r_num.val ≈ 10.0
# r_num.err ≈ 0.02828…  (V/I · sqrt((σV/V)² + (σI/I)²))

Verified in test/examples/test_ohms_law.jl.

2. Voltage divider (sensitivity analysis)

Setup. Input voltage Vin ± σVin, two resistors R1 ± σR1 and R2 ± σR2. Measurand: Vout = Vin · R2 / (R1 + R2).

using SymbolicUncertainties, Symbolics
using SymbolicUncertainties: ±

@variables Vin σVin R1 σR1 R2 σR2

Vout = propagate(
    (v, r1, r2) -> v * r2 / (r1 + r2),
    [Vin ± σVin, R1 ± σR1, R2 ± σR2],
)

Propagation. propagate computes sensitivity coefficients via Symbolics.derivative; repeated operand identity collapses correctly — since M11 this holds through the plain binary operators as well as through propagate.

Uncertainty budget.

df = uncertainty_budget(
    Vout,
    [Vin, R1, R2],
    [σVin, σR1, σR2];
    as = :namedtuple,
)

Numeric result. Vin = 5.0, R1 = 1 kΩ, R2 = 3 kΩ, σVin = 0.01, σR1 = 1.0, σR2 = 1.0:

Vout_num = Symbolics.substitute(
    Vout,
    Dict(Vin => 5.0, R1 => 1_000.0, R2 => 3_000.0,
         σVin => 0.01, σR1 => 1.0, σR2 => 1.0),
)
# Vout_num.val ≈ 3.75 V
# Vout_num.err ≈ 0.00987…  (combined from all three σ)

Verified across test/examples/test_voltage_divider.jl, test_budget_voltage_divider.jl, and test_substitute_voltage_divider.jl.

3. RC time constant (τ = R · C)

Setup. Resistance R ± σR and capacitance C ± σC. Measurand: first-order time constant τ = R · C.

using SymbolicUncertainties, Symbolics
using SymbolicUncertainties: ±

@variables R C σR σC

τ = (R ± σR) * (C ± σC)
# τ.val = R * C
# τ.err = sqrt((σR·C)² + (R·σC)²)

Propagation. Product of two independent inputs — sensitivity coefficients ∂τ/∂R = C and ∂τ/∂C = R. Combined standard uncertainty is τ · sqrt((σR/R)² + (σC/C)²) after simplification.

Uncertainty budget.

uncertainty_budget(τ, [R, C], [σR, σC])

Numeric result. R = 1 kΩ, C = 1 µF, σR = 10 Ω, σC = 10 nF:

τ_num = Symbolics.substitute(
    τ,
    Dict(R => 1_000.0, C => 1e-6, σR => 10.0, σC => 1e-8),
)
# τ_num.val = 1e-3 s (= 1 ms)
# τ_num.err ≈ sqrt((10·1e-6)² + (1000·1e-8)²)
#           = sqrt(1e-10 + 1e-10) ≈ 1.414e-5 s

4. Dissipated power (P = V · I or P = V² / R)

Setup. Voltage V ± σV and current I ± σI. Measurand: dissipated power P = V · I.

using SymbolicUncertainties, Symbolics
using SymbolicUncertainties: ±

@variables V I σV σI

P = (V ± σV) * (I ± σI)
# P.val = V * I
# P.err = sqrt((σV·I)² + (V·σI)²)

Propagation. Product of two independent inputs.

Alternative form using the Ohm's-law substitution I = V / R:

@variables R σR
P_alt = propagate(
    (v, r) -> v^2 / r,
    [V ± σV, R ± σR],
)
# P_alt.val = V² / R
# P_alt.err = sqrt((2V/R · σV)² + (V²/R² · σR)²)

The two forms give different propagated uncertainties because they derive from distinct measurement models — a reminder that the GUM budget depends on which measurements are taken, not on the physical quantity itself.

Numeric result. V = 5.0, I = 0.5, σV = 0.01, σI = 0.001:

P_num = Symbolics.substitute(
    P,
    Dict(V => 5.0, I => 0.5, σV => 0.01, σI => 0.001),
)
# P_num.val = 2.5 W
# P_num.err ≈ sqrt((0.01·0.5)² + (5·0.001)²)
#           = sqrt(2.5e-5 + 2.5e-5) ≈ 0.00707 W

5. RLC resonance (f₀ = 1 / (2π √(LC)))

Setup. Inductance L ± σL and capacitance C ± σC. Measurand: resonant frequency f₀ = 1 / (2π · sqrt(L · C)).

using SymbolicUncertainties, Symbolics
using SymbolicUncertainties: ±

@variables L C σL σC

f₀ = propagate(
    (l, c) -> 1 / (2π * sqrt(l * c)),
    [L ± σL, C ± σC],
)
# f₀.val = 1 / (2π · sqrt(L·C))
# f₀.err = f₀.val/2 · sqrt((σL/L)² + (σC/C)²)

Propagation. propagate handles the sqrt composition symbolically. Sensitivity coefficients are ∂f₀/∂L = -f₀/(2L) and ∂f₀/∂C = -f₀/(2C), giving the half-logarithmic-derivative combined form shown above.

Inverse inference — protocol optimisation (M5).

# What σL is needed so u(f₀) ≤ 0.001·f₀.val ?
required = infer_precision(f₀, σL, 0.001 * f₀.val)
# Closed-form symbolic expression in (L, C, σC) —
# see test/examples/test_rlc_resonance.jl (M5 exit gate).

Numeric result. L = 10 mH, C = 1 µF, σL = 50 µH, σC = 5 nF:

f₀_num = Symbolics.substitute(
    f₀,
    Dict(L => 10e-3, C => 1e-6, σL => 50e-6, σC => 5e-9),
)
# f₀_num.val ≈ 1591.55 Hz
# f₀_num.err ≈ 5.59 Hz  (combined from L and C contributions)

Verified in test/examples/test_rlc_resonance.jl.

6. RC-charge ODE (du/dt = (Vin − u) / (R·C))

Setup. A first-order dynamic measurement — the standard RC charge transient. Parameters R ± σR, C ± σC, Vin ± σVin are treated as constants with uncertainty. This example requires the ModelingToolkit.jl package extension (M9).

using ModelingToolkit
using ModelingToolkit: t_nounits as t, D_nounits as D, System
using SymbolicUncertainties
using SymbolicUncertainties: ±

@variables u(t)
@parameters R C Vin
eqs = [D(u) ~ (Vin - u) / (R * C)]
@named rc_sys = System(eqs, t)

R_m   = R   ± 0.01R
C_m   = C   ± 0.01C
Vin_m = Vin ± 0.001Vin

Symbolic snapshot via propagate_ode:

result = propagate_ode(rc_sys, [R_m, C_m, Vin_m])
# result[1].val = u(t)
# result[1].err = sqrt((∂u/∂R)²·σR² + (∂u/∂C)²·σC² +
#                      (∂u/∂Vin)²·σVin²)

Augmented integration via uncertainty_ode:

using OrdinaryDiffEq

augmented = uncertainty_ode(rc_sys, [R_m, C_m, Vin_m])
compiled  = mtkcompile(augmented)

u0 = Dict(u => 0.0,
          (s => 0.0 for s in setdiff(unknowns(augmented),
                                     unknowns(rc_sys)))...)
p  = Dict(R => 1.0, C => 1e-3, Vin => 5.0)
prob = ODEProblem(compiled, merge(u0, p), (0.0, 50e-3))
sol  = solve(prob, Tsit5(); abstol = 1e-10, reltol = 1e-10)

# sol[u, end] ≈ 5.0  (converged to Vin)
# sol[∂u_∂Vin(t), end] ≈ 1.0

Verified in test/ext_modelingtoolkit/test_rc_charge_endpoint.jl (M9 SC-003 exit gate). For a full walkthrough of the two M9 functions (propagate_ode and uncertainty_ode), see ODE Integration.

Refresh procedure (when Symbolics output drifts)

These examples are backed by dedicated test items in test/examples/ and test/ext_modelingtoolkit/. If a future Symbolics.jl release changes a user-visible output format, the affected example's narrative may become out of date. Procedure:

  1. Run the corresponding test file — julia --project=test -e 'using TestItemRunner; @run_package_tests filter=ti->ti.filename == "…"'.
  2. If the test still passes, no change is needed — the code block in this page is still valid.
  3. If the test fails on output drift, update the test to the new baseline, then mirror the same update in this page.

The test files are authoritative; this page consolidates them for reader convenience.
