Dimensional Analysis

When Unitful.jl is loaded, ErrorPropagation.jl accepts dimensional annotations on the val and err fields of a SymbolicMeasurement and enforces dimensional consistency at construction time. This satisfies IEC 60359 unit- traceability requirements for calibrations.

Matched-dimensions construction

using Symbolics, ErrorPropagation, Unitful

m_v = (5.0u"V") ± (0.1u"V")   # OK — both fields in volts

The resulting SymbolicMeasurement carries the unit annotation through the symbolic machinery. Upstream Symbolics + Unitful interop ensures that the propagation formulas flow dimensions correctly for polynomial and rational measurands.

Dimensional mismatch → DimensionError

(5.0u"V") ± (0.1u"A")
# ┌ DimensionError: (5.0 V, 0.1 A): unequal dimensions
# └

The error is Unitful.jl's standard DimensionError — no custom wrapping. Catch it via try … catch err isa Unitful.DimensionError … end in user code.

Propagation-through-units

Standard arithmetic and propagate flow dimensional annotations through:

V = (5.0u"V") ± (0.01u"V")
I = (0.5u"A") ± (0.001u"A")
R = V / I
# R.val has dimension of V/A = Ω (ohms) — Unitful's
# derived unit system handles the conversion.

Limitations

  • Symbolic manipulation (Symbolics.simplify, Symbolics.derivative) on unit-carrying expressions has some upstream limitations — certain simplification steps may drop units. When in doubt, substitute numeric quantities and verify the resulting dimension before relying on the output.
  • Compound-unit expressions (e.g. u"m/s^2") are fully supported at construction but complex derived units can occasionally produce non-canonical dimensional forms after symbolic propagation.
  • The extension does not re-export Unitful.jl's u"…" macro — users invoke it directly from their own using Unitful import.

IEC 60359 traceability

The ErrorPropagationUnitfulExt extension ensures the val and err of every user-constructed measurement are dimensionally consistent, and that arithmetic flows dimensions through the propagation formulas. This satisfies IEC 60359 §7 unit-traceability requirements for regulated- industry calibration workflows.

See also the Interoperability page for Measurements.jl, DataFrames.jl, and Latexify.jl integrations.
